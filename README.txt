Структура проекта состоит из 2 ключевых частей:
1)Работа с камерой через приложение Dataman Cognex
2)Сервер постобработки на python

Шаги запуска и настройки проекта:
**Dataman-часть:
1) Открыть приложение dataman Cognex
2) Подключить камеру к пк и установить соединение с камерой в приложении
3) Выполнить первичную настройку камеры при необходимости:
	-Настройка фокусировки
	-Выбор сканируемого кода(datamatrix) и установка количества сканируемых кодов
	-Переключение во вкладке Format Data радио тумблер на Script-Based Formating
	-Ввод кода сохраненного в txt файле по адресу: "C:\Users\nayo\Desktop\resultsData\script.txt"
4) Сохраненная конфигурация находится по адресу: "C:\Users\nayo\Desktop\resultsData\config.dmb"
**Python-часть:
1) Открытие любого редактора кода или среду, которая поддерживает python скрипт
2) Запуск python-скрипта, файл находится по адресу: "C:\Users\nayo\Desktop\resultsData\server.py"

Проект запущен, можно делать тестовые триггеры.
